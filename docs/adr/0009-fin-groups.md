# 0009 수집 권역 — 은행·저축은행·여신전문·보험, 금융투자 제외

- 상태: 제안
- 날짜: 2026-11-01
- 담당: 준혁

## 문제

금감원 API 는 요청마다 권역(`topFinGrpNo`) 하나를 고른다. 권역은 레코드 안에 없고 요청 파라미터로만 갈린다. 어느 권역을 매일 받을지 정해야 했다.

## 선택지

1. 은행·저축은행 2권역만
2. **상품이 있는 4권역 — 은행·저축은행·여신전문·보험**
3. 금융투자까지 5권역

## 결정

2번. `FetchService.FIN_GRP_NOS = 020000, 030300, 030200, 050000`. 금융투자(`060000`)는 받지 않는다.
권역별 위치·실측·저장 방식은 [fin-groups.md](../design/fin-groups.md).

## 근거

- 여신전문은 신용대출, 보험은 주담대·전세·신용대출 상품이 있다. 빼면 그 상품군 비교가 반쪽이 된다
- 금융투자는 상품 0건, 회사 7곳뿐이다(2026-11-01 확인). 받아도 쌓이는 상품이 없다

## 결과 · 트레이드오프

- 하루 원문 29페이지 · 4권역(2026-11-17 일일 요약)
- 새로 넣은 권역은 첫 수집일이 기준선이 되고 그날은 변동을 내지 않는다(ADR-0003)
- 금융투자에 상품이 생겨도 자동으로 잡히지 않는다. 목록에 코드를 넣어야 한다
